## 是什么

JeecgBoot 是一个**面向企业内部系统的 AI 低代码开发平台**，基于 Spring Boot + Vue3/Ant Design Vue 构建。核心理念是让开发者"少写重复代码"，让业务人员"零代码搭系统"，让 AI 把这两件事再提速一个数量级。

平台覆盖从数据库设计、代码生成、表单设计器、工作流引擎、报表设计，到权限管理、多租户、微服务扩展的完整企业系统研发链路。在中国开源生态中，JeecgBoot 是最接近"开箱即用的企业 ERP/OA/CRM 底座"的选择，46k+ Stars、16k+ Forks 代表着庞大的工程落地规模。

## 核心功能

| 功能 | 说明 |
|------|------|
| **代码生成器** | 配置数据库表结构，一键生成完整 CRUD 前后端代码（Controller / Service / Mapper / Vue 页面） |
| **零代码表单设计器** | 拖拽组件构建表单，自动生成数据库表和增删改查接口，无需编码 |
| **可视化工作流引擎** | BPM 流程设计器，支持审批流、会签、条件分支，内置流程监控 |
| **报表设计器** | 拖拽式 BI 报表和图表，支持行列汇总、交叉表、图形报表 |
| **权限体系** | 菜单权限 / 按钮权限 / 数据行权限三级控制，开箱即用 |
| **AI Skills** | 自然语言驱动，一句话生成流程图、表单设计、乃至完整子系统 |
| **微服务架构支持** | 内置 Spring Cloud Alibaba 模块，可平滑升级为微服务部署 |
| **多租户** | 支持 Schema 隔离和行级隔离两种多租户模式 |

## AI 能力专项说明

JeecgBoot 的 **AI Skills** 是平台的最新核心层，将 LLM 能力直接嵌入开发流程：

- **自然语言 → 工作流**：描述一个审批流程，AI 自动生成 BPM 流程图，可直接保存并启用
- **自然语言 → 表单设计**：用中文描述字段需求，AI 生成完整拖拽表单（含字段类型、校验规则）
- **自然语言 → 完整系统**：描述一个 CRM 或 HR 模块的需求，AI 生成数据库 Schema + 后端 CRUD API + 前端页面，形成可运行的子系统骨架
- **代码辅助生成**：在代码生成器基础上，AI 负责填充业务逻辑、接口注释、异常处理等重复性代码

这一层的意义在于：传统低代码仍需工程师配置，AI Skills 让业务人员可以直接驱动系统生成，进一步压缩从需求到可用原型的周期。

## 适合场景

- 企业需要快速搭建 OA、ERP、CRM、HR 等内部管理系统
- 团队希望以低代码方式构建定制化业务平台，减少重复 CRUD 开发
- 中台建设：统一权限、工作流、报表底座，各业务线在上面叠加功能
- 用 AI 加速需求原型：需求描述 → AI 生成可运行骨架 → 工程师在此基础上细化

## 注意事项

- 代码生成产物是"骨架"，复杂业务逻辑仍需工程师介入补充，AI 不能完全替代开发
- 技术栈固定为 Java（Spring Boot）+ Vue3，非此栈的团队需评估适配成本
- 功能体系庞大，学习曲线较陡，建议先从官方脚手架和示例项目入手
- AI Skills 功能为较新特性，成熟度和生成质量仍在持续迭代中，生产使用前建议评估输出可靠性
- 微服务模式相比单体模式部署复杂度显著提升，小团队建议先用单体版
