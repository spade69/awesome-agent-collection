## 是什么

Cherry Studio 是一款**面向个人的桌面 AI 工作台**，支持 Windows / macOS / Linux。它把多模型对话、自主 Agent、知识库问答、MCP 工具调用集成到一个客户端里，无需在多个网页和 App 之间切换。

它主打"统一入口 + 本地优先"：一处配置好各家 API Key，就能在同一界面里对比调用前沿模型、管理自定义助手、挂载本地文档知识库，是重度 AI 用户的顺手工具箱。

## 核心特性

- **多模型统一**：一个界面接入 300+ 云端与本地模型，随时切换对比
- **助手与 Agent**：预置大量助手角色，支持自主 Agent 执行任务
- **本地知识库**：挂载文档做 RAG 问答，资料留在本地
- **MCP 支持**：接入 MCP 工具，扩展 Agent 的实际动手能力
- **跨平台桌面**：三大系统原生客户端，离线可用

## 适合场景

- 想要一个统一管理多家模型 API 的桌面客户端
- 需要本地知识库问答，又在意数据留在本机
- 重度 AI 用户希望把对话、助手、工具收进一个应用

## 注意事项

- 定位是客户端/工作台，不是可编程的 Agent 框架
- AGPL-3.0 协议，二次分发/商用集成需注意开源合规
- 多模型能力依赖用户自备各家 API Key
