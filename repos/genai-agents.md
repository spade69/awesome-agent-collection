## 是什么

GenAI_Agents 是一个**按技术点组织的 Agent 实现教程库**。它不讲空泛概念，而是把一个个具体的 Agent 技术（ReAct、反思、规划、多 Agent 协作、RAG 编排等）各做成一个可运行的 Notebook，从最简单的对话机器人一路覆盖到复杂系统。

社区活跃、内容持续增长，适合"我想做 X 能力，找个参考实现"这种查阅式学习。

## 内容覆盖

- **入门**：简单对话 Agent、带记忆的 Agent
- **核心技术**：ReAct、工具调用、任务规划、自我反思
- **RAG 相关**：检索增强、多来源整合
- **多智能体**：协作、辩论、角色分工等编排模式
- **实战应用**：数据分析、研究、自动化等落地案例

## 核心价值

- **技术点齐全**：50+ 种技术各有独立实现，覆盖面广
- **即学即跑**：Notebook 形式，clone 下来就能运行调试
- **循序渐进**：从最简到复杂，适合按需深入
- **社区驱动**：持续更新，紧跟新技术

## 适合场景

- 想按具体技术点找参考实现的开发者
- 学完框架后需要大量实战案例练手
- 做技术选型时快速比较不同 Agent 模式
