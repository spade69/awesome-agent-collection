## 是什么

Cua 是一套 **面向 Computer-Use Agent 的开源基础设施**。当 Agent 需要真正"操作电脑"——截屏理解界面、移动鼠标、点击、键盘输入——Cua 提供跨操作系统的驱动、可并行的沙箱环境集群，以及训练/评测/数据生成所需的基准工具。

它解决的是 Computer-Use 落地的工程底座问题：不只是"能操作一台机器"，而是能**跨系统、成规模地跑 Agent**，并为模型训练与能力评测提供可复现的环境和数据。

## 核心特性

- **跨系统驱动**：统一接口驱动不同操作系统的 GUI 操作
- **沙箱集群**：可并行的隔离环境，安全承载大量 Agent 任务
- **评测基准**：内置 benchmark，用于能力评测与横向对比
- **训练与数据**：支持为 Computer-Use 模型生成训练/评测数据
- **开源 MIT**：底层驱动开放，可自由集成

## 适合场景

- 构建需要真实操作桌面/网页的 Computer-Use Agent
- 需要规模化、可隔离地运行与评测 GUI Agent
- 训练或基准测试 Computer-Use 模型，需要可复现环境

## 注意事项

- 定位是底层基础设施，不是即用的成品 Agent
- 大规模沙箱运行有资源与运维成本
- Computer-Use 稳定性受目标应用界面变化影响
