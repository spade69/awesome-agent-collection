## 是什么

Khoj 是一个**可自托管的个人 AI 助手平台**。它将你的私人文档（笔记、PDF、代码、邮件）与实时网络搜索融合，通过持久记忆系统逐步了解你的偏好和背景，并支持创建自定义 AI Agent 完成复杂任务。

设计理念是隐私优先：所有数据可完全本地存储，支持接入 Ollama 等本地 LLM，避免隐私数据上传至第三方。提供 Web 界面、桌面应用、Obsidian 插件、Emacs 插件等多种访问方式。

## 核心功能

| 功能 | 说明 |
|------|------|
| **文档问答** | 索引 Markdown、PDF、Word、代码等文件，语义检索后精准回答 |
| **网络搜索** | 实时搜索网络内容，结合个人知识库综合回答 |
| **持久记忆** | 自动从对话中提取用户偏好和背景，跨会话持续学习 |
| **自定义 Agent** | 创建具有特定工具、指令和知识库的个性化 Agent |
| **多前端接入** | Web 应用、桌面客户端、Obsidian 插件、Emacs 插件 |
| **本地 LLM 支持** | 通过 Ollama 接入本地模型，数据不离本机 |
| **图像理解** | 支持上传图片进行视觉问答 |
| **语音交互** | 支持语音输入，适合移动端和免手操场景 |

## 适合场景

- **个人知识管理**：将 Obsidian/Notion 笔记、PDF 收藏、技术文档变成可对话的知识库
- **研究辅助**：结合网络搜索和本地资料，快速综合多源信息
- **隐私敏感场景**：完全自托管 + 本地 LLM，不向任何云服务暴露私人数据
- **长期个人助手**：记忆系统会随时间积累对用户的了解，越用越懂你
- **团队共享知识库**：部署一个实例，供小团队共享内部文档问答

## 注意事项

- 协议为 AGPL-3.0，商业集成需注意许可条款
- 自托管需要一定的 Docker/Python 部署能力，配置相对复杂
- 使用云端 LLM（OpenAI/Anthropic）时文档内容仍会发送至对应服务商，真正完全私有需搭配 Ollama
- 文档索引质量依赖嵌入模型，本地模型的检索精度低于云端模型
- 记忆系统自动写入，长期使用后建议定期清理无关记忆条目
