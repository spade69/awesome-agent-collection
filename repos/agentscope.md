## 是什么

AgentScope 是阿里巴巴开源的多 Agent 开发框架，源自论文（arXiv:2402.14034），聚焦解决多 Agent 系统落地生产时最痛的问题：**黑盒不可控**。框架内置可视化调试工具，让开发者能追踪每个 Agent 的推理链路、工具调用和消息流转，而不是靠打印日志排查。

## 核心特性

| 特性 | 说明 |
|------|------|
| **可观测性优先** | 内置 Trace 可视化，Agent 间通信全程可查 |
| **多 Agent 编排** | 原生支持 Agent 间协作、竞争、层级调用模式 |
| **学术背书** | 有配套论文，架构设计经过研究验证 |
| **中文文档完整** | 官方维护中文主页和文档，中文社区友好 |

## 适合场景

- 生产环境多 Agent 系统，需要排查"Agent 为什么这么做"而不只是"Agent 做了什么"
- 团队已有阿里云生态依赖，希望框架与云服务集成顺畅
- 学术研究场景需要可复现、可追溯的多 Agent 实验框架

## 注意事项

- 相比 LangGraph/AutoGen 等国际化程度更高的框架，生态插件数量仍在追赶
- 深度可观测性功能通常意味着更多运行时开销，高并发场景需评估性能
