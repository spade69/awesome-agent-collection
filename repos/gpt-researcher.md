## 是什么

GPT Researcher 是一个专注于**自动化深度研究**的 Agent 框架。它模仿人类研究员的工作流：提出问题、并行搜索多个来源、交叉验证信息、过滤噪音，最终输出结构化的研究报告。

设计上特别注重解决 LLM 研究的两大问题：**速度慢**（串行搜索）和**偏见**（依赖单一来源）。

## 核心架构

| 组件 | 作用 |
|------|------|
| **Planner Agent** | 分解研究问题，生成并行子查询 |
| **Researcher Agent** | 并行执行多路搜索和内容抓取 |
| **Editor Agent** | 整合信息，消除矛盾，生成报告 |
| **Reviewer Agent** | 审核报告质量，触发补充研究 |

## 核心功能

- **并行深度搜索**：同时向多个搜索引擎和数据源发起查询，大幅提升速度
- **多来源对比**：自动交叉验证不同来源，减少单一来源偏见
- **本地文档研究**：支持对本地 PDF、Word、CSV 等文件做深度分析
- **多种报告格式**：研究报告、简报、资源列表、详细大纲等
- **实时流输出**：研究过程可实时流式展示，支持 WebSocket
- **多搜索引擎**：Tavily、DuckDuckGo、Google、Bing、Arxiv 等

## 与 deer-flow 的对比

| 维度 | GPT Researcher | deer-flow |
|------|---------------|-----------|
| 专注领域 | 信息研究与报告生成 | 通用长周期任务执行 |
| 核心优势 | 并行搜索 + 去偏见 | 子 Agent + 沙箱执行 |
| 输出形式 | 研究报告（带引用） | 多种任务结果 |
| 代码执行 | 不支持 | 支持 |

## 适合场景

- **市场调研**：自动收集竞品信息、行业趋势
- **学术文献综述**：批量搜索、整理论文摘要
- **新闻分析**：多角度汇总某一事件的报道
- **投资尽调**：自动收集公司背景、财务信息

## 注意事项

- 搜索质量强依赖底层搜索 API（推荐 Tavily，需付费）
- 长报告可能消耗大量 token，建议搭配 prompt caching
- 输出内容需人工审核，不适合直接发布
