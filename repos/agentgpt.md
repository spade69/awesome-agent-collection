## 是什么

AgentGPT 是 Reworkd 开源的**浏览器端自主 Agent 平台**，用户在网页中以自然语言描述一个目标，AI 会自动将其分解为子任务并逐步执行，直到目标达成或陷入循环。整个过程完全可视化，无需本地安装任何环境，接入自己的 OpenAI API Key 即可运行。

它是 2023 年"AutoGPT 热潮"期间最具代表性的同类项目之一，凭借零门槛的网页体验迅速获得数万 Star，也帮助大量开发者直观理解了 Agent Loop 的运作机制。目前项目维护活跃度已低于鼎盛时期，更多作为教学演示用途。

## 核心功能

| 功能 | 说明 |
|------|------|
| **目标驱动执行** | 用自然语言输入目标，AI 自动拆解为可执行子任务 |
| **Agent Loop** | 循环迭代执行任务，直到目标达成或检测到卡死 |
| **浏览器全栈运行** | 前端 Next.js，后端 FastAPI，无需本地 CLI 环境 |
| **自带 API Key 接入** | 用户填入 OpenAI Key 后即可使用，无需后端代理 |
| **插件 / 工具支持** | 内置网页搜索、代码执行等工具，可扩展 |
| **任务历史可视化** | 实时展示每一步思考过程和执行结果 |

## 适合场景

- **学习 Agent Loop 原理**：直观观察 Plan → Act → Observe → Repeat 的完整闭环
- **快速演示自主 Agent 概念**：向非技术人员展示 AI 自主执行任务的能力
- **原型验证**：低门槛验证某个目标是否适合 Agent 自动化处理
- **教学与课程**：讲解 Autonomous Agent 架构时的配套实践工具

## 注意事项

- 项目目前维护活跃度较低，不建议直接用于生产环境
- Agent Loop 容易陷入死循环或无效重复，实际完成复杂任务的成功率有限
- 依赖 OpenAI API，不支持本地模型（官方版本）
- GPL-3.0 协议对商业使用有传染性限制，需注意合规
- 与 LangChain Agent、CrewAI 等更成熟框架相比，可定制性和稳定性较弱
- 更适合理解概念和教学，生产级自主 Agent 推荐参考 AutoGen、CrewAI 等替代方案
