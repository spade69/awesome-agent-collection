## 是什么

DeepEval 是一个简单易用的 **开源 LLM 评测框架**，用法类似 Pytest，但专为 LLM 应用的单元测试设计。内置基于最新研究的指标（如 G-Eval、任务完成度、答案相关性等），可评测端到端应用、完整 Agent 轨迹以及单个步骤。

## 核心特性

- **自定义通用指标**：G-Eval、DAG（基于图的确定性评审构建器）、JevEval
- **Agent 指标**：任务完成度、工具正确性、目标准确度、步骤效率、计划遵循度与质量、参数正确性
- **RAG 指标**：答案相关性、忠实度、上下文召回 / 精确度 / 相关性、RAGAS
- **多轮对话指标**：如知识保留等
- **灵活的评测模型**：可用任意 LLM，或在本地运行的统计 / NLP 模型，指标均附带解释
- **多粒度评测**：端到端黑盒、完整轨迹、单步（LLM 调用、工具、检索、子 Agent 交接）
- 配套商业平台 Confident AI 用于对比迭代、共享报告与线上监控

## 适合场景

- 想用熟悉的测试范式给 LLM / Agent / RAG 做回归测试
- 要在 CI 里卡质量门槛、对比不同模型或提示词
- 需要丰富现成指标而不想自己设计评审提示词

## 注意事项

- 本身是评测框架，线上追踪与团队协作需配合 Confident AI 等商业平台
- 基于 LLM 的指标会消耗模型调用费用，结果受评审模型影响
- 评测结果仍需结合人工抽检校准
