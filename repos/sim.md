## 是什么

Sim 是一个**开源的 AI Agent 可视化编排平台**，让开发者和非技术人员都能通过拖拽界面构建、测试、部署多 Agent 工作流。它定位为企业 AI 工作力（AI workforce）的中央协调层，把各种 AI 能力（LLM 调用、工具使用、数据处理）连接成可复用的流程。

## 核心功能

| 功能 | 说明 |
|------|------|
| **可视化编排** | 拖拽节点构建 Agent 工作流，无需编码 |
| **多 Agent 协作** | 多个专职 Agent 并行/串行协作 |
| **内置工具集** | HTTP 请求、代码执行、数据库查询等开箱即用 |
| **实时调试** | 可视化追踪每个节点的输入输出 |
| **版本管理** | 工作流版本控制，支持回滚 |
| **API 触发** | 工作流可通过 Webhook/API 触发，集成外部系统 |

## 技术架构

- **前端**：Next.js + React Flow 可视化画布
- **后端**：Node.js 工作流引擎
- **存储**：PostgreSQL 持久化工作流和执行记录
- **部署**：Docker 一键自托管

## 适合场景

- **非技术用户**：运营、产品团队自主构建 AI 工作流
- **快速原型**：可视化验证多 Agent 协作方案
- **企业自动化**：客服、内容生产、数据处理等重复任务自动化
- **AI 工作力**：用多个专职 Agent 替代部分人工流程

## 注意事项

- 复杂逻辑（动态分支、递归）在可视化界面中较难表达
- 自托管需要维护 PostgreSQL 和 Node.js 服务
- 相比 LangGraph 等代码框架，灵活性有所牺牲
