## 是什么

TradingAgents 是一个 **多智能体 LLM 金融交易框架**（配套 arXiv 论文）。它把一家交易机构的决策链路抽象成多个 Agent 角色：基本面/技术面/情绪面分析师、看多看空研究员、交易员、风险管理团队，让它们像真人团队一样分工、辩论、汇总，最终产出交易决策。

它的价值不在于"给一个买卖信号"，而在于**用可解释的多角色协作流程还原投研决策是如何形成的**，是研究"多智能体协作 + 金融决策"这一交叉方向的代表性开源实现。

## 核心特性

- **分角色 Agent**：分析师团队、研究员（多空辩论）、交易员、风控分层协作
- **决策流程可解释**：每个角色的观点和辩论过程透明可追溯
- **多源信息**：整合行情、基本面、新闻情绪等多维输入
- **可配置**：可替换底层 LLM、调整角色与流程参数
- **论文支撑**：附带研究论文，方法论有据可循

## 适合场景

- 研究多智能体协作在金融决策中的应用
- 想理解"投研团队决策流程"如何用 Agent 建模
- 作为量化/金融 Agent 实验的起点框架

## 注意事项

- 面向研究与教育，**不构成投资建议**，实盘需自担风险
- 依赖行情/新闻数据源与 LLM 调用，运行有成本
- 决策质量受底层模型和数据质量影响较大
