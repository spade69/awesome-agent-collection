## 是什么

这是微软推出的**AI Agent 系统性入门课程**，用 18 节课把 Agent 开发从概念讲到实战。每一课都是独立主题 + 可运行的代码示例，学完能真正搭出自己的 Agent。

作为微软官方课程，它覆盖主流框架（AutoGen、Semantic Kernel、Azure AI Agent Service 等），并提供多语言字幕，是目前 Star 最高的 Agent 教学资源之一。

## 课程覆盖

| 主题 | 说明 |
|------|------|
| **Agent 简介与用例** | 什么是 Agent、适用场景 |
| **Agent 框架** | 主流框架对比与选型 |
| **设计模式** | 工具使用、规划、多 Agent、反思等模式 |
| **RAG 与知识** | 检索增强、知识接入 |
| **可信 Agent** | 安全、评估、生产化 |
| **元认知与规划** | 让 Agent 会拆解、会反思 |

## 核心价值

- **系统性**：从概念到落地循序渐进，不是零散片段
- **可运行**：每课带代码，学完即可上手
- **官方权威**：微软出品，紧跟 Azure AI 与主流框架
