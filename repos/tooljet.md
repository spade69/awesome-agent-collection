## 是什么

ToolJet 是一个**开源低代码内部工具构建平台**，核心提供可视化拖拽构建器，连接 50+ 数据源（数据库、REST API、SaaS 工具），快速搭建企业内部应用。

近期推出的 **ToolJet AI** 层让产品完成了关键跃迁：不再需要手动拖拽组件、手写查询——只需用自然语言描述"我要一个客户管理系统，支持搜索、新增、状态流转"，AI 直接生成完整应用结构（页面布局、数据查询、交互逻辑）。

定位是中小团队和企业工程师快速交付内部工具，替代依赖工程资源反复迭代的传统开发模式。

## 核心功能

| 功能 | 说明 |
|------|------|
| **拖拽式构建器** | 50+ 内置组件：表格、表单、图表、按钮、自定义组件，所见即所得 |
| **50+ 数据源集成** | PostgreSQL、MySQL、MongoDB、REST API、GraphQL、Stripe、Airtable、Firebase 等 |
| **JavaScript / Python 执行** | 在应用内直接写逻辑代码，不受组件限制 |
| **工作流自动化** | 可视化自动化流程构建（类 n8n），与应用深度集成 |
| **角色权限控制** | 细粒度 RBAC，支持多团队、多应用隔离 |
| **多环境部署** | 内置 dev / staging / prod 环境切换，安全上线 |
| **自托管** | 支持 Docker、Kubernetes、Heroku 一键部署，数据不出私有环境 |

## ToolJet AI 功能

ToolJet AI 是平台的 AI 原生层，核心能力：

- **自然语言 → 完整应用**：描述业务需求（"一个支持筛选和导出的订单管理面板"），AI 生成页面结构、组件布局、数据查询逻辑
- **应用修改指令**：已有应用上用自然语言追加功能（"给这个表格加一列状态标签"）
- **SQL / API 查询生成**：根据上下文自动生成数据查询语句，无需手写
- **组件属性建议**：AI 根据数据结构推荐合适的组件配置

这使 ToolJet 成为目前**最接近"自然语言 → 可运行内部工具"全栈方案**的开源平台。

## 适合场景

- 需要快速搭建 CRM、库存管理、工单系统等内部 CRUD 应用
- 工程资源有限、希望业务人员自助构建简单工具的团队
- 已有多套数据库 / API，需要统一操作界面的企业
- 想用 AI 生成应用原型、再精调细节的产品/工程团队

## 注意事项

- AGPL-3.0 协议：SaaS 商用需购买企业版授权（社区版限制较少，但商业分发需注意）
- ToolJet AI 部分功能属于云端收费服务，自托管版 AI 能力有所差异
- 复杂业务逻辑仍依赖 JavaScript/Python 手写，AI 生成结果需人工核查
- 与纯代码框架相比，灵活性存在上限，深度定制场景需评估
