## 是什么

Serena 是一个 **面向编码的 MCP 工具箱**。它把 LSP（语言服务器协议）能力封装成 MCP 工具，让任意支持 MCP 的 Agent（Claude、各类编码 Agent 等）获得符号级的代码检索、跳转、引用查找与精确编辑能力。

它解决的核心痛点是：大多数 Agent 改代码靠全文搜索和整段替换，既慢又容易改错。Serena 让 Agent 像 IDE 那样"按符号"操作代码——找到函数定义、列出所有引用、精准替换某个符号，从而在大型代码库里可靠地工作。

## 核心特性

- **符号级语义检索**：基于 LSP 按符号查找定义、引用，而非字符串匹配
- **精确编辑**：以符号为单位插入/替换代码，减少误伤
- **MCP 原生**：作为 MCP Server 接入任意兼容 Agent
- **多语言**：随底层语言服务器支持多种编程语言
- **免费开源**：给现有 Agent 白嫖一套"代码大脑"

## 适合场景

- 想让编码 Agent 在大型代码库里更精准地检索和改代码
- 已有 MCP 客户端（如 Claude），需要补强代码理解能力
- 不想为 Agent 自建 LSP 集成的团队

## 注意事项

- 定位是工具层，需要搭配 MCP 客户端/Agent 使用
- 各语言能力取决于对应语言服务器的成熟度
- 许可为分组件授权，集成时留意各组件协议
