## 是什么

Kilo Code 是一个"随处可用"的 AI 编码 Agent：在 VS Code 插件、JetBrains 插件和终端 CLI 里提供一致体验。它整合了 Roo Code / Cline 的能力路线，主打**开放定价 + 超多模型**，让开发者不被单一模型或厂商锁定。

## 核心特性

| 特性 | 说明 |
|------|------|
| **500+ 模型** | GPT、Claude、Gemini 等主流模型任选，任务中途可随时切换 |
| **零加价** | 直接按模型提供商原价计费，平台不抽成 |
| **全平台** | VS Code、JetBrains、CLI、Cloud Agent 一套账号通用 |
| **开箱即用** | 创建账号即可开始，无需自备 API Key |
| **开源开放** | 代码与定价全透明，社区驱动迭代 |

## 与竞品对比

| 维度 | kilocode | cline | opencode |
|------|----------|-------|----------|
| 卖点 | 500+ 模型 + 零加价 | 人工确认每步 | Go 单二进制极速 |
| 形态 | IDE + CLI + Cloud | IDE + CLI | 终端 CLI |
| 计费 | 模型原价直付 | 自备 Key | 自备 Key |

## 适合场景

- 想频繁比较、切换不同模型而不想被锁定的开发者
- 不愿折腾多个 API Key、希望统一入口即开即用
- 同时在 VS Code 与 JetBrains 之间切换的多 IDE 用户

## 注意事项

- 走平台账号计费虽零加价，但重度使用仍需关注模型本身费用
- 功能高速迭代，部分能力仍在快速演进中
