## 是什么

Flowise 是一个**面向非技术用户和快速原型的可视化 AI 构建工具**。基于 LangChain.js，提供拖拽画布让用户可视化组合 LLM、工具、知识库、记忆等组件，构建从简单问答到复杂多步骤 Agent 的各类 AI 应用。

以极低的上手门槛著称，是入门 AI Agent 开发的首选工具之一。

## 核心功能

| 功能 | 说明 |
|------|------|
| **拖拽画布** | 100+ 预置节点，无需写代码 |
| **聊天界面** | 内置可嵌入的聊天 Widget |
| **API 端点** | 工作流自动暴露为 REST API |
| **文档 QA** | 内置 PDF/文档问答流程模板 |
| **Agent 工具** | 搜索、计算器、自定义 API 调用等内置工具 |
| **一键部署** | Docker/Railway/Render 一键部署 |

| 维度 | Flowise | Langflow |

## 适合场景

- **快速原型**：30 分钟内验证 AI 应用想法
- **非技术用户**：产品、运营团队自主搭建 AI 工具
- **内部工具**：企业内部 FAQ 机器人、文档问答

## 注意事项

- 依赖 LangChain.js，复杂自定义需要写节点代码
- 相比代码框架灵活性有限，生产级复杂场景可能受限
- 社区模板质量参差不齐，需甄别
