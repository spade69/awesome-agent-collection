## 是什么

Coze Loop（扣子罗盘）是面向开发者的 **AI Agent 开发与运维平台**，提供从开发、调试、评测到监控的全生命周期管理。开源版基于商业版推出，免费开放核心基础功能模块，开发者可按业务需要定制扩展。

## 核心特性

- **提示词开发**：可视化 Playground 实时交互调试与对比，支持版本管理
- **评测**：管理评测集、评估器和实验，对提示词与 Coze 智能体输出做准确性、简洁性、合规性等多维度自动化测试
- **可观测**：记录从用户输入到 AI 输出的完整执行过程，含提示词解析、模型调用、工具执行等关键环节，支持 SDK 上报追踪
- **模型接入**：支持 OpenAI、火山方舟等模型
- **部署**：Docker Compose（`make compose-up`）或 Kubernetes Helm Chart

## 适合场景

- 在使用 Coze / 火山方舟生态、需要中文友好的 Agent 开发运维平台
- 想一站式管理提示词、评测集和线上追踪
- 要求私有化部署的团队

## 注意事项

- 开源版仅含核心基础功能，与商业版有差距
- 需先在配置文件中填写模型的 api_key 与 model 才能使用
- 公网部署前需评估账号注册、监听地址、SSRF 等安全风险
- 项目偏新，生态与集成广度不及老牌方案
