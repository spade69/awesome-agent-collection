## 是什么

awesome-ai-agents 是由 **E2B（AI 代码沙箱厂商）维护的 Agent 生态清单**。它把市面上的自主 AI Agent 相关项目按类别整理成一份持续更新的列表，覆盖开源框架、闭源平台、垂直应用等，并为每个条目附上简介和链接。

作为一份 awesome 列表，它的价值在于**降低信息检索成本**：想快速了解"当前有哪些 Agent 框架/平台/工具"，从这里入手能一眼看清生态全貌，再按需深入。

## 核心特性

- **分类清晰**：按开源/闭源、框架/平台/应用等维度归类
- **持续更新**：社区 PR 驱动，跟进新项目
- **条目带简介**：每个项目附一句话说明与链接
- **生态视角**：由基础设施厂商维护，覆盖面较全
- **纯文档**：clone 即读，无需运行
