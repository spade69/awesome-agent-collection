## 是什么

RAGFlow 是专注于**深度文档理解**的开源 RAG 引擎。大多数 RAG 系统只是简单地把文档切成文本块然后向量化，遇到含表格、图表、复杂排版的 PDF 就会丢失大量信息。RAGFlow 引入了专门的文档解析引擎，能识别文档结构、提取表格数据、理解图文关系，显著提升在企业文档上的问答准确率。

## 核心特性

| 特性 | 说明 |
|------|------|
| **深度文档解析** | 专用 OCR + 布局分析，理解表格、图表、多栏排版 |
| **智能分块策略** | 根据文档类型自动选择最优分块方式 |
| **引用溯源** | 每个答案都能追溯到原文档的具体位置 |
| **多格式支持** | PDF、Word、Excel、PPT、HTML、Markdown 等 |
| **混合检索** | 向量检索 + 关键词检索融合，提升召回率 |
| **知识图谱** | 支持构建文档间关联的知识图谱 |

## 与普通 RAG 方案对比

| 维度 | RAGFlow | 简单切块 RAG |
|------|---------|------------|
| 表格理解 | 精准提取结构化数据 | 通常丢失结构 |
| 图表处理 | OCR + 图文关联 | 忽略或乱码 |
| 引用溯源 | 精确到段落/行 | 仅到文档级 |
| 复杂 PDF | 专项优化 | 效果差 |

## 适合场景

- **企业知识库**：财报、合同、技术手册等复杂文档的问答
- **法律/金融文档分析**：需要精确引用来源的合规场景
- **学术文献检索**：论文、研究报告的深度理解
- **政府/医疗文档**：大量非结构化 PDF 的知识提取

## 注意事项

- 深度解析比简单切块消耗更多计算资源
- 复杂文档解析速度较慢，不适合实时处理场景
- 自托管需要较高配置，官方建议 16GB+ 内存
