## 是什么

LobeHub（由 Lobe Chat 演进而来）是一个 **现代开源 AI Agent 工作站**。它把单纯的聊天前端升级为"Chief Agent Operator（首席 Agent 运营官）"范式：用户像管理团队一样雇佣、编排多个专职 Agent，让它们全天候协作运营。仍保留了 Lobe Chat 时代精美的 UI 与丰富的多模型接入能力。

## 核心功能

| 功能 | 说明 |
|------|------|
| **多 Agent 编排** | 组织多个专职 Agent 分工协作，7×24 运转 |
| **多模型接入** | OpenAI / Anthropic / Google / 本地模型统一接入 |
| **插件 / 工具生态** | 函数调用 + 插件市场，扩展 Agent 能力 |
| **知识库 / RAG** | 上传文件构建私有知识库 |
| **精美 UI** | 业界口碑极佳的现代化界面，PWA + 移动端友好 |
| **自托管** | 支持 Docker 一键部署，数据可私有化 |

## 从 Lobe Chat 到 LobeHub

- **Lobe Chat 时代**：定位精美的多模型聊天前端
- **LobeHub 时代**：升级为 Agent 运营平台，强调"编排一支 Agent 团队"而非单轮对话

## 适合场景

- **个人 AI 工作站**：一个界面统一管理多模型、多 Agent
- **私有化部署**：企业/团队自托管，数据不出内网
- **重界面体验**：需要开箱即用、UI 精致的 Agent 前端

## 注意事项

- 采用自定义协议，商业化使用前需仔细阅读授权条款
- 功能丰富带来一定上手成本，纯轻量聊天场景可能偏重
- 自托管需维护数据库与部署环境
