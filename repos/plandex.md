## 是什么

Plandex 是一个**面向终端的 AI 编程 Agent**，核心特点是专为复杂、多文件、跨模块的大型项目设计。它引入了**沙箱（sandbox）机制**：Agent 的所有修改先写入沙箱，人工审查通过后才应用到实际文件，同时内置版本控制，任何步骤都可以回滚。

相比 Claude Code 等工具，Plandex 更强调"安全地"完成长任务，而不是快速完成短任务。

## 核心设计

| 设计 | 说明 |
|------|------|
| **沙箱执行** | 所有改动先在沙箱中积累，不直接修改源文件 |
| **版本控制** | 每一步操作都有版本记录，可精确回滚到任意状态 |
| **上下文管理** | 精细控制哪些文件/内容进入 Agent 上下文 |
| **任务规划** | 自动将大任务分解为可跟踪的子步骤 |
| **持续执行** | 支持长时间运行，自动处理错误和重试 |

## 核心功能

- **多文件协调修改**：Agent 理解跨文件依赖，统一规划修改方案
- **流式输出**：实时查看 Agent 的思考和执行过程
- **上下文注入**：可将文档、README、接口定义等加入上下文
- **自托管支持**：完整的自托管方案，数据不出本地
- **多模型支持**：OpenAI、Anthropic、Gemini、本地模型

## 与 Claude Code 的对比

| 维度 | Plandex | Claude Code |
|------|---------|-------------|
| 沙箱保护 | 核心特性，强制沙箱 | 有但非强制 |
| 适合任务 | 大型复杂项目 | 各类任务 |
| 终端体验 | 专注终端，无 IDE 插件 | CLI + IDE 扩展 |
| 版本控制 | 内置细粒度回滚 | 依赖 git |
| 模型绑定 | 模型无关 | 绑定 Claude |

## 适合场景

- **大型重构**：涉及几十个文件的系统性改造
- **功能开发**：从设计到实现的完整功能模块
- **不熟悉的代码库**：让 Agent 探索并修改陌生项目
- **高风险修改**：需要沙箱保护的生产级代码变更

## 注意事项

- AGPL 协议的云服务版按 token 计费，自托管版完全免费
- 沙箱机制增加了一定操作复杂度，不适合追求速度的简单改动
- 目前不支持 IDE 插件，纯终端工具
