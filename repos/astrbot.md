## 是什么

AstrBot 是一个面向即时通讯场景的**全能型 Agent 平台**。无论要做个人 AI 伴侣、智能客服、自动化助手还是企业知识库，都能在 IM 工作流内快速落地为生产级 AI 应用，为个人、开发者和团队提供可靠可扩展的对话式 AI 基础设施。

## 核心特性

| 特性 | 说明 |
|------|------|
| **多平台接入** | QQ、企业微信、飞书、钉钉、公众号、Telegram、Slack 等一网打尽 |
| **完整 Agent 能力** | LLM 对话、多模态、MCP、Skills、知识库、人格设定、自动上下文压缩 |
| **1000+ 插件** | 插件市场一键安装扩展功能 |
| **Agent 沙箱** | 隔离安全执行代码 / shell，会话级资源复用 |
| **平台集成** | 可对接 Dify、阿里云百炼、Coze 等外部 Agent 平台 |
| **WebUI + Web ChatUI** | 内置管理后台与网页聊天界面，含 Agent 沙箱与联网搜索 |

## 特色

- **开箱即用**：Docker 部署 + WebUI 配置，无需重度编码
- **主动 Agent**：支持 Proactive Agent 主动发起对话与任务
- **国际化**：内置 i18n，多语言界面
- **中文友好**：文档、社区、插件生态中文覆盖充分

## 适合场景

- 想在 QQ / 微信 / 飞书群里部署智能问答或客服机器人
- 搭建带知识库的企业内部 IM 助手
- 个人 AI 伴侣 / 角色扮演陪伴类应用

## 注意事项

- AGPL-3.0 协议具传染性，商用集成前请确认合规
- 对接各 IM 平台需分别处理其账号 / API 合规与风控问题
- 生产部署建议开启 Agent 沙箱，避免代码执行风险
