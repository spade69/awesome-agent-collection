## 是什么

Agno 是一个 **Python 全栈 Agent 框架**（前身即知名的 Phidata）。它不满足于"拼装一个能对话的 LLM"，而是把构建生产级 Agent 需要的能力——推理、工具、记忆、知识库、多智能体协作、可观测——做成一套统一的高层 API。

它的定位介于"轻量 SDK"和"重型平台"之间：既能像写普通 Python 一样快速起 Agent，又内置了团队编排、会话存储、监控面板等生产要素，适合从原型直接演进到线上服务。

## 核心特性

- **模型无关**：统一接口接入 OpenAI / Anthropic / Gemini 及众多开源模型
- **多智能体团队**：支持 Agent 组队协作、任务路由与角色分工
- **记忆与知识**：内置会话记忆 + 向量知识库（RAG），Agent 自带上下文
- **工具生态**：大量预置工具，也可自定义函数一键注册为工具
- **可观测**：自带监控与调试面板，追踪每一步推理和工具调用
- **性能导向**：主打轻量实例化和高并发下的低开销

## 适合场景

- 想用 Python 快速搭建带记忆和知识库的生产级 Agent
- 需要多智能体协作，又不想自己造编排/存储/监控轮子
- 从 Phidata 迁移，或在"轻 SDK"与"重平台"之间寻找平衡点

## 注意事项

- 高层封装带来便利，深度定制时需理解其抽象分层
- 生态与 API 迭代较快，升级需关注版本变更
- 生产部署仍需自行考虑扩缩容、存储与密钥管理
