## 是什么

awesome-llm-apps 是一个 **可运行的 LLM/Agent 应用示例大全**。不同于纯 awesome 链接列表，这里每个条目都是**完整可跑的项目代码**，覆盖 RAG、多 Agent 协作、自主 Agent、语音 Agent、MCP 应用等主题，用 OpenAI、Anthropic、Gemini 以及开源本地模型实现。

## 内容分类

| 类别 | 示例 |
|------|------|
| **Starter Agents** | 入门级单 Agent 示例 |
| **Advanced Agents** | 深度研究、金融分析等复杂 Agent |
| **Multi-Agent** | 多智能体协作团队 |
| **RAG** | 各种检索增强生成实现（含 Agentic RAG） |
| **MCP Apps** | 基于 Model Context Protocol 的应用 |
| **Voice / Game / Memory** | 语音 Agent、游戏 Agent、带记忆的 Agent |

## 价值

- **即学即用**：每个项目自带 README 和依赖，clone 后按说明即可运行
- **框架多样**：横跨 LangChain、CrewAI、Agno、OpenAI SDK 等，横向对比学习
- **模型全覆盖**：闭源 API 与本地开源模型均有示例
- **持续更新**：社区活跃，紧跟最新 Agent 玩法

## 适合场景

- **入门学习**：想快速看懂 Agent/RAG 是怎么落地的
- **抄作业**：需要某类应用的起手模板，直接拿现成代码改
- **技术选型**：对比同一需求在不同框架下的实现差异

## 注意事项

- 是示例合集而非生产框架，代码以"讲清楚"为目标，生产化需自行加固
- 各示例质量与维护度不一，部分依赖版本可能滞后
- 需自备各家模型的 API Key
