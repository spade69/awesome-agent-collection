## 是什么

Mem0 是一个**专为 AI Agent 设计的持久化记忆系统**。标准 LLM 每次对话都从零开始，无法记住用户偏好、历史决策或长期上下文。Mem0 在 Agent 和 LLM 之间插入一个记忆层，自动从对话中提取有价值的信息，智能存储并在需要时检索注入上下文。

支持个人级记忆（记住特定用户）、Agent 级记忆（Agent 自身的学习积累）和会话级记忆（当前任务上下文）。

## 核心架构

| 层次 | 说明 |
|------|------|
| **记忆提取** | LLM 自动从对话中识别值得记忆的信息 |
| **记忆存储** | 向量数据库（Qdrant/Pinecone/Chroma）+ 图数据库 |
| **记忆检索** | 语义相似度 + 时间衰减的智能检索 |
| **记忆更新** | 自动合并、去重、更新冲突记忆 |

## 核心功能

- **自动记忆提取**：无需手动标注，LLM 自动判断哪些信息值得保留
- **多层次记忆**：用户级、Agent 级、会话级分开管理
- **智能检索**：根据当前对话语义自动拉取相关历史记忆
- **记忆管理 API**：查看、编辑、删除特定记忆
- **框架无关**：支持 LangChain、CrewAI、AutoGen、原生 API
- **云服务**：提供托管版，无需自建向量数据库

## 典型用法

```python
from mem0 import Memory

m = Memory()

# 添加记忆
m.add("I prefer Python over JavaScript", user_id="alice")

# 搜索相关记忆
results = m.search("programming preferences", user_id="alice")
# → [{"memory": "Prefers Python over JavaScript", ...}]
```

## 适合场景

- **个人助手应用**：记住用户偏好、工作习惯、历史决策
- **客服 Agent**：跨会话记住客户信息和历史问题
- **长期任务 Agent**：积累执行经验，避免重复犯错
- **个性化推荐**：基于用户历史行为的动态个性化

## 注意事项

- 记忆提取质量依赖底层 LLM，复杂信息可能提取不准确
- 存储成本随用户规模增长，大规模部署需规划向量数据库
- 托管云服务付费，自托管需配置向量数据库
