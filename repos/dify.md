## 是什么

Dify 是一个**端到端的 AI 应用开发与运营平台**。不同于只做工作流编排的工具，Dify 覆盖 AI 应用的完整生命周期：从 Prompt 工程、知识库管理、Agent 编排，到生产部署、用户管理、使用监控、A/B 测试。

定位是让企业用最低成本把 LLM 能力落地成真实业务应用，无论是内部工具还是面向用户的产品。

## 核心功能

| 功能 | 说明 |
|------|------|
| **工作流编排** | 可视化构建复杂多步骤 Agent 流程 |
| **知识库（RAG）** | 文档上传、向量化、检索一体化管理 |
| **Prompt 工程** | 可视化调试 Prompt，版本管理，A/B 测试 |
| **Agent 模式** | 工具调用、函数调用、ReAct 多种 Agent 策略 |
| **应用发布** | 一键生成 Web UI、API、嵌入式 Widget |
| **运营监控** | 对话日志、用量统计、成本追踪 |
| **多租户** | 企业版支持多工作空间、权限管理 |

## 与 Langflow 对比

| 维度 | Dify | Langflow |
|------|------|---------|
| 全生命周期覆盖 | 完整（含运营监控） | 偏构建阶段 |
| 非技术用户友好性 | 更友好 | 偏技术 |
| 生产就绪度 | 极高 | 中等 |
| 框架依赖 | 无依赖，自研引擎 | 依赖 LangChain |
| 社区规模 | 极大 | 大 |

## 适合场景

- 企业内部知识库问答系统
- 客服机器人、销售助理等面向用户的 AI 产品
- 需要 Prompt 版本管理和 A/B 测试的产品团队
- 多部门共用一套 AI 基础设施

## 注意事项

- 开源版附加条款：商用部署超过一定规模需购买企业版
- 功能全面但也意味着部署和维护成本较高
- 工作流的灵活性不如纯代码框架（LangGraph 等）
