> **一句话**：给 AI 生成的代码提供一个安全、弹性的运行沙箱——毫秒级启动隔离环境，让 Agent 放心地执行、测试它自己写出来的代码，而不用担心搞坏宿主机。

## 是什么

Daytona 是一套**面向 AI 生成代码的安全运行基础设施**。当 Agent 写出代码需要真正跑起来验证时，直接在本机执行有风险（删文件、跑死循环、装恶意依赖），Daytona 提供隔离沙箱来解决这个问题。

它主打"安全 + 弹性"：每个任务在独立环境中运行，秒级甚至毫秒级创建/销毁，天然适配 Coding Agent、代码解释器这类需要频繁执行不可信代码的场景。

## 核心特性

- **快速创建**：沙箱环境毫秒级启动，支持大规模并发
- **强隔离**：代码在隔离运行时执行，保护宿主与其他任务
- **SDK 优先**：Python / TypeScript SDK，几行代码把"执行环境"嵌入 Agent
- **文件与进程管理**：沙箱内文件读写、命令执行、进程控制完整 API
- **弹性伸缩**：按需分配资源，任务结束即回收

## 适合场景

- Coding Agent / 代码解释器需要安全执行 LLM 生成的代码
- 需要为大量并发 Agent 任务提供隔离运行环境
- 想给"AI 写代码 → 立即运行验证"闭环补上安全沙箱那一环

## 注意事项

- 定位是底层运行时基础设施，不是完整的 Agent 框架
- 自托管有一定运维成本，云托管则涉及资源费用
- AGPL-3.0 协议，商用集成需注意开源合规要求
