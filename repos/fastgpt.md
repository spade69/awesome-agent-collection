> **一句话**：以知识库和 RAG 精度为核心的可视化 AI 工作流平台，内置多阶段混合检索、数据处理流水线和一键 API 发布，是构建企业知识问答系统的开箱即用方案。

## 是什么

FastGPT 是一个**面向知识库问答的 AI 应用平台**。核心出发点是让 RAG 真正可用于生产：通过多阶段检索（向量检索 + 全文检索 + Rerank）来提升召回准确率，配合可视化工作流编排复杂问答逻辑，最终一键发布为 API 或对话机器人。

相比 Dify 的广度优先，FastGPT 在知识库管理和 RAG 准确性上投入更深，是国内大量企业知识库项目的首选平台，拥有庞大的中文社区。

## 核心功能

| 功能 | 说明 |
|------|------|
| **可视化工作流** | 拖拽式编排多步骤 AI 流程，支持条件分支、循环、并行节点 |
| **多阶段 RAG 检索** | 向量检索 + 全文检索混合，支持 Rerank 二次排序 |
| **知识库管理** | 支持 URL、文件、手动输入多种导入方式，自动分块与向量化 |
| **数据处理流水线** | 清洗、去重、预处理可配置，提升入库质量 |
| **一键 API 发布** | 工作流直接暴露为 OpenAI 兼容 API，无需额外开发 |
| **团队协作** | 多成员、多知识库权限管理，支持组织级隔离 |
| **对话日志** | 完整记录问答过程，支持人工标注和反馈优化 |

## 与 Dify 对比

| 维度 | FastGPT | Dify |
|------|---------|------|
| 核心定位 | 知识库问答 / RAG 精度 | 全生命周期 AI 应用平台 |
| RAG 能力深度 | 深（混合检索 + Rerank + 多阶段） | 中（基础 RAG，可扩展） |
| 工作流灵活性 | 中等 | 较高 |
| 运营监控 | 基础 | 完整（含成本、A/B 测试） |
| 中文社区 | 极活跃 | 活跃 |
| 部署复杂度 | 中（Docker Compose） | 中（Docker Compose） |
| 协议限制 | Custom，大规模商用需确认 | Apache-2.0 附加条款 |

## 适合场景

- 企业内部文档知识库问答（政策、手册、FAQ）
- 客服知识库机器人，要求高召回准确率
- 需要快速搭建 RAG 原型并验证效果的团队
- 中小团队希望低代码完成知识库 + 工作流集成

## 注意事项

- 协议为 Custom 源码可见，商业使用前需仔细阅读 LICENSE 条款
- RAG 效果依赖 Embedding 模型质量，中文场景建议使用专用中文 Embedding 模型
- 工作流节点自定义扩展能力不如纯代码框架（LangGraph 等）
- 自部署需额外维护向量数据库（支持 pgvector、Milvus 等）
