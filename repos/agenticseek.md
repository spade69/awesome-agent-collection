## 是什么

agenticSeek 是一个**完全本地化的自主 Agent**，定位是 Manus AI 的开源替代品。它不依赖任何外部 API，用 Ollama/LM Studio 等工具运行本地模型，实现自主浏览网页、执行代码、管理文件等能力。

对于关注数据隐私、不愿支付高额 API 费用的用户，agenticSeek 提供了一个真正可落地的本地 AI Agent 方案。

## 核心功能

| 功能 | 说明 |
|------|------|
| **网页浏览** | 自主搜索和浏览互联网，提取信息 |
| **代码执行** | 编写并运行 Python、JavaScript 等代码 |
| **文件管理** | 读写文件，管理本地目录结构 |
| **多 Agent 协作** | 将任务分配给专职子 Agent 并行处理 |
| **语音交互** | 支持语音输入输出（可选） |
| **完全本地** | 全程离线，无数据泄露风险 |

## 技术架构

- **本地模型**：通过 Ollama 运行 Qwen、DeepSeek、Llama 等开源模型
- **路由系统**：自动判断任务类型，分发给最合适的专职 Agent
- **沙箱执行**：代码在隔离环境运行，保障安全
- **记忆管理**：对话历史和任务状态持久化存储

## 推荐模型配置

| 任务 | 推荐模型 |
|------|---------|
| 通用推理 | Qwen2.5-72B、DeepSeek-R1 |
| 代码生成 | DeepSeek-Coder-V2、Qwen2.5-Coder |
| 轻量快速 | Qwen2.5-7B、Llama-3.2-3B |

## 与 deer-flow 对比

| 维度 | agenticSeek | deer-flow |
|------|------------|-----------|
| 运行方式 | 完全本地 | 云端 API |
| 费用 | 仅电费 | 按 token 计费 |
| 隐私 | 最高 | 数据上云 |
| 模型质量 | 受本地算力限制 | 可用最强云端模型 |
| 设置难度 | 较高（需本地模型） | 低 |

## 适合场景

- **隐私敏感任务**：不想让数据离开本地的企业或个人
- **持续高频使用**：API 费用压力大的重度用户
- **离线环境**：无法访问外网的内网环境
- **学习研究**：完整可读的本地 Agent 实现，便于学习

## 注意事项

- 性能受本地硬件限制，建议至少 16GB 内存 + GPU
- 本地模型质量与 GPT-4/Claude 仍有差距，复杂推理任务可能出错
- GPL-3.0 协议：基于此开发的项目需开源
