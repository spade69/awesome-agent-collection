## 是什么

OpenHands（原 OpenDevin）是定位最接近 Devin 的开源项目，目标是构建**真正能完成软件工程全流程的 AI Agent**。它不只是代码补全工具，而是一个能独立完成从理解需求、搜索资料、编写代码、运行测试到提交 PR 的完整软件工程任务的 Agent 系统。

在 SWE-bench 上取得了顶级成绩，是衡量 AI 软件工程能力的重要基准。

## 核心架构

| 组件 | 作用 |
|------|------|
| **Agent Controller** | 任务规划与执行调度 |
| **沙箱环境** | Docker 隔离的代码执行环境 |
| **浏览器工具** | Agent 可自主搜索网页获取信息 |
| **终端工具** | 完整 shell 访问，运行任意命令 |
| **文件系统** | 完整读写项目文件的能力 |

## 核心功能

- **完整软件工程循环**：理解需求 → 搜索资料 → 写代码 → 测试 → 调试 → 提交
- **多 Agent 架构**：不同专职 Agent 协作（规划、编码、测试）
- **浏览器访问**：能主动搜索文档、Stack Overflow、GitHub Issues
- **Docker 沙箱**：所有操作在隔离容器中执行，安全可控
- **多模型支持**：Claude、GPT-4、本地模型均可作为后端
- **Web UI**：提供完整的任务管理和进度监控界面

## 与 SWE-agent 对比

| 维度 | OpenHands | SWE-agent |
|------|----------|---------|
| 定位 | 完整 AI 软件工程师 | GitHub Issue 自动修复 |
| 界面 | Web UI + CLI | 纯 CLI |
| 浏览器能力 | 有（主动搜索） | 无 |
| 多 Agent | 是 | 否 |
| 生产就绪度 | 较高 | 研究级 |

## 适合场景

- 自动化完成 GitHub Issue 修复
- 让 Agent 独立完成功能开发任务
- 代码库重构、依赖升级等重复性工程任务
- 研究 AI 软件工程能力的学术团队

## 注意事项

- 复杂任务的成功率仍有限，需要人工验收
- 每次任务 token 消耗较大，建议使用 prompt caching
- 沙箱环境需要 Docker，本地部署有一定门槛
